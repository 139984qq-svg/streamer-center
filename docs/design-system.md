## 1. 设计令牌 Design Tokens

集中命名、复用的设计值,组件引用令牌而非硬编码数值。改一个令牌即全站同步,主题切换也依赖它。

### 1.1 颜色 Color

采用克制灰阶 + 单一强调色的苹果式方案。深浅主题各一组。

| 令牌 | 浅色 | 深色 | 用途 |
|---|---|---|---|
| `color.bg` | `#FFFFFF` | `#000000` / `#0A0A0C` | 页面背景 |
| `color.bg.subtle` | `#F5F5F7` | `#1C1C1E` | 次级背景、卡片浮层底 |
| `color.text.primary` | `#1D1D1F` | `#F5F5F7` | 主文字 |
| `color.text.secondary` | `#6E6E73` | `#A1A1A6` | 次要文字、说明 |
| `color.text.tertiary` | `#86868B` | `#8E8E93` | 辅助文字、时间戳 |
| `color.border` | `#D2D2D7` | `#3A3A3C` | 分割线、描边(细) |
| `color.accent` | `#0071E3`(蓝) | `#0A84FF` | 单一强调色:主 CTA、选中、关键数字 |
| `color.success` | `#1D9A38` | `#30D158` | 上升趋势、成功 |
| `color.danger` | `#D70015` | `#FF453A` | 下降趋势、错误 |

要点:
- 单一强调色 + 灰阶即满足"克制的灰阶 + 单一强调色"。趋势红绿仅作辅助,深色下提高明度保证对比度。
- 强调色不用在正文,只用于可识别为"主操作/关键信息"的位置。

### 1.2 字体 Typography

- 系统字体栈: `-apple-system, BlinkMacSystemFont, "SF Pro Display", "SF Pro Text", "Helvetica Neue", "PingFang SC", "Microsoft YaHei", sans-serif`。
- 字号采用非整数细腻 # 档,靠近苹果刻度。

### 1.3 间距 Space

复用固定档位,不用空格/空行挤位置:
- 紧凑 `4px` / 适中 `8px` / 宽松 `16px`(基准档),页面级 `24/32/48/64px` 大留白。
- 相关元素贴近(标签↔输入框 `8px`),不相关模块拉开(`>=24px`)。组内 < 组间。
- Margin(卡片间)、Padding(内容↔边框)、Gap(内部元素)三者统一按档位取。

### 1.4 圆角 Border Radius

按角色收敛少量档位,同类一致,不任意混用:
- `radius.sm`: `6px` —— 输入框、按钮、标签
- `radius.md`: `10px` —— 小卡片、浮层
- `radius.lg`: `18px` —— 大卡片、面板
- `radius.full`: `999px` —— 胶囊标签/胶囊按钮、圆形头像(`50%`)。
- 装小字体控件用小圆角,容器圆角更大;容器有圆角须配 `overflow: hidden` 裁切子内容。

### 1.5 阴影 Shadow

阴影只辅助表达层级,统一光源方向(顶部),浅色界面克制:
- `shadow.sm`: `0 1px 2px rgba(0,0,0,.05)` —— 普通卡片(默认近平)
- `shadow.md`: `0 4px 12px rgba(0,0,0,.10)` —— 悬停浮起、下拉、Tooltip
- `shadow.lg`: `0 12px 32px rgba(0,0,0,.18)` —— 弹窗、抽屉等最上层
- `shadow.inset`(内阴影): 输入框、进度槽凹陷感。
- 忌每个元素都加/过深/方向不一致;绝不给正文加投影。

## 2. 排版层级 Typography Hierarchy

| 层级 | 参考值 | 字重 | 颜色 | 用途 |
|---|---|---|---|---|
| 页面标题 Page Title | `34px/40px` | 600 | primary | 看板页名 |
| 模块标题 Section Title | `22px/28px` | 600 | primary | 卡片/区块标题 |
| 指标值 Statistic Value | `28-34px` | 600-700 | primary | 关键统计数字 |
| 正文 Body | `16px/1.55` | 400 | primary | 主要阅读 |
| 辅助 Caption | `12-13px` | 400 | tertiary | 时间、备注、来源 |

要点:
- 层级用"字号 + 字重 + 颜色深浅"拉开,差距要一眼可分;勿整页同重、勿把警告做成过小过浅。
- 强调重点用加粗/变色,只标真正关键处;整段加粗 = 无重点。
- 用间距管理对齐,勿用全角空格模拟对齐。

## 3. 视觉层级 Visual Hierarchy

让访客按"主标题 → 说明 → 操作"顺序浏览。诊断口诀:**眯眼看页面,第一落点是否为主标题。**

三种手段:
1. **大小**:越重要越大,差距拉开到一眼可分。
2. **颜色深浅**:重要深色、次要浅一档;全页同深浅 = 无主次。
3. **位置与底色**:靠上先被看到;按钮靠底色而非字号跳出;图片是视觉锚点。

注意:层级 ≠ 排版(排版只管文字);层级 ≠ 内容顺序(顺序按逻辑,层级管"看到快慢")。

## 4. 布局模式 Layout

### 4.1 侧边栏布局 Sidebar(看板主框架)
- 左侧栏放层级导航(分组菜单),右侧内容区 `flex: 1` 弹性伸缩。
- 侧栏可收起成一排图标,给内容区让位;定义侧栏固定/收起宽度与折叠态。
- 移动端改为带遮罩 + 关闭入口 + 正确焦点管理的抽屉(Drawer)。
- 忌:侧栏混入公告/广告、内容区宽度写死、层级深时默认全部展开(应折叠)。

### 4.2 首屏 Hero
- 标题一句话讲清产品为谁解决什么问题 + 补充说明讲清结果 + 突出一个主 CTA + 必要产品画面。
- 5 秒扫读测试:能否复述价值。客户 logo、全部功能、定价/FAQ 属于后续区块,不进首屏。

### 4.3 响应式 Responsive
- 让任务在任意宽度仍可读、可点、可完成;断点是阈值,媒体查询是实现。
- 例:`@media (max-width: 720px){ .cards{ grid-template-columns:1fr; } }`。
- 三列 → 单列;窄屏放大触控目标、折叠次要导航、表格/侧栏重排。
- 用 DevTools `Cmd+Shift+M` 模拟手机验证 390px 与 1440px 是否无挤压/横向溢出。

## 5. 组件规范 Components

统一"何时用 + 关键注意"提炼,每组件 3-6 行。

### 5.1 卡片 Card
- **何时用**:同一对象集合(推荐流/数据/商品)、仪表盘每指标一块、把长页切成分组、图片占比大的内容。
- **注意**:整张卡可点要清楚;局部操作由链接/按钮分别承担,勿误触跳转。
- **忌**:纯文字长文套卡片、卡片嵌卡片(双层边框竞争)、每条仅一行改用列表、整页唯一内容硬套框。
- 变体:基础 / 带封面(图顶) / 无边框 Flat(背景已分区) / 带操作。

### 5.2 表格 Table
- **何时用**:多行同构数据需逐列比较、需排序/筛选/行内操作、后台管理主体视图。
- **注意**:排序/筛选/分页须明确当前状态;排序后各列仍对应同一行。
- **忌**:少量行用描述列表;图文混排用列表/卡片;手机窄屏铺满列频繁横滑(保留关键列,其余进详情)。
- 变体:基础 / 斑马纹(行多) / 紧凑(密集) / 排序。

### 5.3 图表 Chart
- **何时用**:比较类别大小用柱状图、观察时间趋势用折线图;先问"要比较什么"再选图。
- **注意**:必须有标题、时间范围、单位、坐标、图例;重要精确值给标签/提示;颜色不能是唯一线索。
- **忌**:用饼图藏对比、折线硬连离散类目;独立图表不能替代可核对/可导出的数据表。

### 5.4 统计数值 Statistic
- **何时用**:仪表盘核心指标(销售额/活跃用户)、带涨跌趋势、实时数据、卡片内小指标。
- **注意**:主值醒目放大,辅助信息明确"较 X 增加/下降 Y%";只写 `↑12%` 不说明比较对象 = 无意义。
- **忌**:展示不必要精度(23.4782%)、同区域堆过多大数字、完成进度用进度条、需"状态结论"用标签。
- 趋势色仅辅助:趋势用红绿,金融场景遵循当地颜色约定。

### 5.5 标签页 Tabs
- **何时用**:同一页面切换几组平级内容(全部/进行中/已完成)、详情分块、平级内容少且常来回切、文案简短。
- **注意**:始终标出当前标签(高亮+下划线);保留各页签合理状态;验证鼠标/键盘切换、小屏不被裁。
- **忌**:有先后用步骤条、标签过多放不下(改用菜单/选择器)、需左右对照并排展示、标签里有未保存表单。
- 变体:线条型(默认)/ 卡片型 / 胶囊型。

### 5.6 空状态 Empty
- **何时用**:请求成功但无数据的列表/表格、搜索无结果、需引导创建第一条数据。
- **注意**:文案说明"为什么空 + 下一步能做什么",并提供明确的引导按钮(新建项目/添加成员)。
- **忌**:只写"暂无数据"(无原因无下一步)、加载中仍显示空态(应骨架/加载)、加载失败伪装成空态、插画比文案花哨。

### 5.7 加载 Spinner
- **何时用**:按钮提交后短暂等待(防重复提交)、局部内容刷新、无法计算总量的处理。
- **注意**:配状态文字说明正在处理的任务;时间长须给取消/重试/失败结果。
- **忌**:已知完成度用进度条;整页轮廓可预测用骨架屏;无限旋转无出口。
- 与进度条(有已知进度) / 骨架屏(占整页轮廓)区分开。

### 5.8 轻提示 Toast
- **何时用**:保存/提交成功、复制链接/验证码结果、轻量失败("网络异常,重试"即可)、不想打断当前操作。
- **注意**:文案简短直接;位置与停留时间勿遮挡当前任务;成功/失败用文字+图标区分,勿同样式。
- **忌**:需用户处理后才能继续的错误(用弹窗)、内容多或带跳转(用通知)、连续弹多条(遮挡+难读)。

### 5.9 侧边栏导航(见 4.1)
- 侧栏只承载层级导航与分组;顶栏放面包屑/搜索/头像;内容区随侧栏伸缩。

## 6. 深色模式 Dark Mode

深色模式是一套可切换的整套界面状态,而非把背景涂黑。

- 背景、文字、边框、输入框、错误、焦点、图表、代码块**全部**需对应主题值,不能只反转一个底色。
- 读系统 `prefers-color-scheme` 作默认,并提供用户显式切换并记住。
- 切换后默认/悬停/选中/聚焦/错误状态仍须可辨;深色下强调色与红绿提高明度。
- 红色下降/绿色上升:深色背景用 `#FF453A` / `#30D158`,保证对比。
- 令牌驱动:浅深两套 `color.*` 值通过令牌切换,组件无感知同步。

## 7. 响应式规则 Responsive Rules

- 断点建议: `sm 768px` / `md 1280px` / `lg 1536px`(参考 Tailwind `sm/md/lg` 语义)。

```
@mixin media-sm  { @media (max-width: 720px)  }
@mixin media-md  { @media (min-width: 768px)  }
@mixin media-lg  { @media (min-width: 1280px) }
```

| 断点 | 列数 | 侧栏 | 表格 | 触控 |
|---|---|---|---|---|
| ≥1536 | 4 | 常驻完整 | 全列 | — |
| ≥1280 | 3 | 可收起 | 全列 | — |
| ≥768 | 3(→2) | 触发折叠 | 关键列+横向 | 目标 ≥44px |
| <768 | 1 | 抽屉 Drawer | 关键列+详情 | 目标 ≥44px |

## 8. 动效规范 Motion

用 CSS `transition` 实现状态平滑渐变;明确 `property / duration / easing`。

- **声明具体属性**,勿用 `transition: all`(width/padding 意外也会被动画)。
- **优先过渡 transform 与 opacity**(性能最好,不触发重排);宽高过渡谨慎(引发重排)。
- **按时长按任务**:短反馈更快(如 `.15s`),较大位移可更长;勿套固定时长。
- **默认 easing**: `ease-out`(`cubic-bezier(.4,0,.2,1)`),入场用 `ease-out`、退场用 `ease-in`。
- **推荐时长**:悬停/开关/变色 `.15-.25s`;弹窗遮罩 `.3s` opacity。
- **尊重用户** `prefers-reduced-motion`,关闭非必要运动。
- 颜色过渡 `background`,变换过渡用 `transform`,弹窗淡入淡出用 `opacity`。
- 例:`transition: background .25s ease-out;` / 开关滑块 `transition: transform .2s ease-out;`。

## 9. 附:毛玻璃 Backdrop Blur(点缀用)

苹果式界面常用半透明浮动层,作质感点缀而非主背景。

- 用 `backdrop-filter: blur()` + **半透明底色**(如 `rgba(255,255,255,.55)`)成对;无透明度则 blur 不生效。
- 适用:吸顶导航(内容滚过若隐若现)、浮层/对话框、配图区信息卡。
- 忌:不透明背景上用 blur、铺大段正文(降性能+对比度)、透明度过高/模糊过轻(文字读不清)、移动端叠多层模糊。
- 必须提供不支持/低性能时的纯色回退。

## 10. 落地检查清单 Checklist

- [ ] 颜色/间距/圆角/阴影全部走令牌,全局无硬编码数值
- [ ] 每页层级 5 秒可辨:第一落点 = 页面主标题
- [ ] 深色与浅色下默认/悬停/聚焦/错误状态均可用
- [ ] 390px 与 1440px 检查无挤压无横向溢出
- [ ] 所有动效声明具体属性 + 时长 + easing,尊重减少动态效果
- [ ] 空态 / 加载 / 失败三种状态分离,不互相冒充
