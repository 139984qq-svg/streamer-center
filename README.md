# VTuber 虚拟直播运营 · AI 工作台

基于 B站真实数据的虚拟直播（VTuber）品类运营看板，单页 Web 应用。

## 功能模块
- **运营大盘**：KPI 六卡、人气榜、主播分层、涨粉榜、复盘指标
- **开播监控**：实时直播状态监控，可跳转直播间
- **主播中心**：全网 VTuber 主播库（B站虚拟区真实抓取）
- **数据分析**：Excel 导入与指标分析
- **内容企划库**：每日推荐轮换 + 档期倒计时
- **粉丝社群**：圈层热词与粉丝画像
- **全网资讯**：V圈新闻通稿，自动抓取官方活动
- **直播复盘**：留存/停留/开播率图表与单场 AI 复盘
- **数据日报**：每日 KPI 与历史归档

## 自动数据链（GitHub Actions）
| 频率 | 内容 |
|---|---|
| 每 30 分钟 | 直播状态刷新 |
| 每日 0:00（北京） | 全网资讯 + 粉丝社群 + 活动链接 |
| 每日 22:05（北京） | 全量主播抓取 + 企划 + 复盘 + 日报 |

## 数据说明
示例项目为锚定 B站虚拟主播分区（area_id=9）的真实运营场景，全部数据由脚本定时抓取生成。

## 技术栈
纯原生 JS / CSS（无框架），Hash 路由单页应用，Python 标准库抓取脚本。
